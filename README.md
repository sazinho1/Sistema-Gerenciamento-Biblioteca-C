# Sistema de Gerenciamento de Biblioteca em C

Este projeto consiste em um Sistema de Gerenciamento de Biblioteca desenvolvido em linguagem C para a disciplina de Estrutura de Dados.

A aplicação permite:

- cadastrar livros;
- buscar livros por código;
- listar livros em diferentes percursos da árvore;
- realizar empréstimos;
- devolver livros;
- controlar reservas por fila;
- registrar histórico de empréstimos.

Os livros são armazenados em uma Árvore Binária de Busca organizada pelo código identificador, permitindo buscas e listagens eficientes. Além disso, o sistema utiliza uma fila para gerenciamento de reservas e uma lista encadeada para armazenamento do histórico de empréstimos realizados.
